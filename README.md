# 📊 Projeto Final - Análise de Dados com Pandas

Este repositório contém um projeto de análise exploratória de dados utilizando a biblioteca **Pandas**, com base em um dataset real sobre desempenho de estudantes portugueses do ensino médio.

## 🧠 Objetivo

Aplicar os principais conceitos de **manipulação, limpeza, análise e visualização de dados** com Pandas, consolidando o aprendizado das operações fundamentais da biblioteca.

## 📌 Dataset

O dataset utilizado foi extraído da base do UCI Machine Learning Repository: [Student Performance Data Set](https://archive.ics.uci.edu/ml/datasets/Student+Performance)

Contém informações como:
- Idade, sexo, tipo de moradia
- Histórico familiar e educacional
- Notas escolares (G1, G2, G3)
- Tempo de estudo, atividades extracurriculares, faltas
- Consumo de álcool, acesso à internet, entre outros

## 📈 Etapas do Projeto

1. **Importação e exploração dos dados**
2. **Limpeza do DataFrame**
3. **Criação de colunas com média, mediana e desvio padrão**
4. **Classificação dos alunos em “Aprovado” ou “Reprovado”**
5. **Filtragem de dados com múltiplas condições**
6. **Agrupamento e cálculo de estatísticas**
7. **Visualizações com gráficos de barras, histogramas e boxplots**

## 📊 Visualizações Geradas

- Quantidade de aprovados vs reprovados
- Distribuição das médias finais dos alunos
- Comparação das médias por sexo

## 💻 Tecnologias Utilizadas

- Python 3.10+
- Pandas
- Matplotlib
- Google Colab

## 📂 Arquivo

- `projeto_pandas.ipynb`: notebook com todo o código do projeto, explicações e gráficos.
